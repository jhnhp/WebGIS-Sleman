# Screenshot

Setelah membuka `index.html` dan memastikan semua layer tampil:

1. tampilkan panel layer,
2. aktifkan ketiga layer,
3. klik salah satu Puskesmas agar popup terlihat,
4. ambil screenshot,
5. simpan sebagai `webgis-screenshot.png` di folder ini.
